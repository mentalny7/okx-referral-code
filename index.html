What is an OKX referral code?

An OKX referral code (also called an invite code or promo code) is a short number that links your new account to an existing OKX user. OKX uses it to reward both sides. The person who invited you gets a share of the fees you pay. You get a part of that share back as a fee discount, plus access to the welcome rewards that OKX runs for new accounts.

The code can only be added during registration. There is no field for it in the account settings later, so it's worth taking ten seconds to paste it in before you hit "Sign up".
